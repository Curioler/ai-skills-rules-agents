# Open questions

Things not yet decided, parked deliberately so that nobody — human or agent — quietly decides them mid-implementation.

**Rule: if you need an answer to one of these in order to write code, stop and ask.** Do not pick one and carry on.

When a question is answered it moves to [Closed](#closed) at the bottom, as one line pointing at the record. It is not deleted — knowing a question was asked, and where it was settled, is worth keeping.
