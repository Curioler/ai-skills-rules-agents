# Ideas

Anything that occurs mid-task but **is not** the task. One line each, no design,
no discussion — the point is that it is not lost and does not derail the work in
progress.

The discipline is the value. An idea written down in one line costs nothing; the
same idea followed for twenty minutes costs the task you were on. Neither losing
it nor chasing it is acceptable, so it lands here instead.

Distinct from its neighbours:

- `docs/decisions/` — choices already **made**, with reasoning
- `docs/open-questions.md` — questions deliberately left **open**, that block or shape future work
- `docs/learning.md` — lessons already **paid for**
- this file — thoughts not yet worth any of the above

Delete an entry when it is done, promoted to a spec, or decided against. A line
that has sat here for months and still reads as a good idea is telling you
something; so is one that no longer does.
